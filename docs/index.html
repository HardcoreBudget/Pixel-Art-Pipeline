Pixel-Art-Pipeline

Pixel-art character and prop designs from a text prompt, made locally with Krea 2 Turbo and a pixel-art LoRA in ComfyUI, then layered, rigged and animated in Pixel Art Studio, the Unity plugin. It is the pipeline the Pixel Art Studio trailer cast and the two scenes below were designed with.

The repository on GitHub See the showcases

Install in one line

Linux / macOS (macOS untested) 
curl -fsSL https://raw.githubusercontent.com/HardcoreBudget/Pixel-Art-Pipeline/main/install.sh | bash
Windows PowerShell (being tested by the maintainer) 
irm https://raw.githubusercontent.com/HardcoreBudget/Pixel-Art-Pipeline/main/install.ps1 | iex

The installer clones ComfyUI and the ComfyUI-GGUF node at tested commits, makes a Python venv, downloads the six model files (about 13 GB) and checks each SHA-256, and asks before installing the two Claude Code skills. Tested on Linux. Read each model's licence before you download it: the Krea 2 Community License allows commercial use only under US$1M annual revenue. Details, requirements and every licence are in the README.

python scripts/krea.py "a young farmer with a straw hat, a plaid shirt and a tin watering can" --name farmer --pixel 64

How it works

  1. Design

    scripts/krea.py asks Krea 2 Turbo with the 64-grid pixel LoRA for one design: one art pixel per 16 px block. About 7 minutes on a 4 GB GPU.

  2. Snap to the grid

    The background is removed and the picture is snapped to its grid, then imported into the plugin with the palette matched in Lab.

  3. Peel and rig

    Pixel Art Studio peels the design into layers, fills what each piece hides and proves the stack still equals the design.

  4. Animate

    Pieces turn about their joints, frame by frame, by hand or by an agent through the plugin's verbs. The pixel-scene skill holds the method.

Pixel Art Studio for Unity

The layering, rigging and animation happen in Pixel Art Studio, a pixel-art editor inside the Unity Editor: layers, indexed palettes and ramps, animation and tags, tiles, rigs and poses, and a scripting surface that agents drive. Its user manual ships inside the package (Assets/PixelArtStudio/Documentation/PixelArtStudio-Manual.pdf), and chapter 25, "Designs from a prompt", walks through this pipeline.
